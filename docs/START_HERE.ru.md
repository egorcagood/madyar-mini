# Как повторить Madyar Mini

**Разработано Егором совместно с ИИ-помощником Codex от OpenAI.** Автор и инициатор проекта — [Егор / egorcagood](https://github.com/egorcagood).


Это исходники экспериментальной сборки, а не универсальная прошивка для любого корпуса SmallTV. Работа автора проверена на одной ревизии SmallTV-Ultra; публичная версия получила другой свободный шрифт и нейтральные настройки. Её сборка проверена, отдельная прошивка на вашем устройстве не проверялась.

## 1. Что нужно

- GeekMagic SmallTV-Ultra с подтверждёнными ESP8266/ESP-12F, flash4MiB и ST7789 240×240. По одной надписи на корпусе ревизию не определяют.
- Windows, Python3.12, GitHub ZIP или Git; домашняя Wi-Fi сеть2,4ГГц.
- USB–UART с **сигналами 3,3В**, например проверенный CP2102; мультиметр для проверки уровней и стабильное USB-питание часов. Надпись3,3В на выходе питания адаптера сама по себе не доказывает уровень TXD.
- Надёжное соединение с площадками платы. Не держите провода руками при записи; пропадающий контакт — причина остановиться.

На первой версии установка требует вскрытия и UART. Обычный USB часов обычно даёт питание и не заменяет UART. Кто не уверен в определении площадок и пайке, должен обратиться к человеку с опытом.

## 2. Скачайте и подготовьте окружение

На GitHub выберите Code → Download ZIP и распакуйте в папку без кавычек, обратных апострофов, знаков доллара и переноса строки. Пробелы/кириллица проверены. Откройте PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r firmware/requirements-build.txt
.\.venv\Scripts\python.exe -m pip install esptool==4.8.1
```

Команды esptool ниже относятся именно к4.8.1 (подчёркивания); у5.x названия изменены. COM-порт определите в диспетчере устройств. Значение `COM_N` в примерах замените своим.

## 3. Подключение — без питания

[Откройте схему](uart-wiring.svg). Это **названия сигналов**, не расположение площадок слева направо. Найдите GND, TX, RX и GPIO0 по схеме/маркировке именно своей платы; если не удалось — остановитесь.

- TXD адаптера → RX часов; RXD адаптера → TX часов.
- GND адаптера → GND часов.
- GPIO0 часов → общая GND для старта загрузчика.
- Выводы питания5V/3V3 адаптера свободны; часы получают питание через свой USB.

ESP8266 требует правильных состояний GPIO15/GPIO2; в данной ревизии они разделены с дисплеем. Не подключайте их наугад и не притягивайте GPIO2 напрямую к питанию. [Официальная справка Espressif](https://docs.espressif.com/projects/esptool/en/latest/esp8266/advanced-topics/boot-mode-selection.html).

После проверки соединений подключите адаптер к ПК, затем обычное USB-питание часов. Чёрный экран сам по себе не доказывает вход в загрузчик: нужен ответ esptool.

## 4. Сначала полный бэкап

Команды выполняются из корня проекта. Запись ещё не выполняется:

```powershell
New-Item -ItemType Directory -Force local-backup | Out-Null
.\.venv\Scripts\python.exe -m esptool --chip esp8266 --port COM_N --baud 115200 flash_id
.\.venv\Scripts\python.exe -m esptool --chip esp8266 --port COM_N --baud 115200 read_flash 0x0 0x400000 local-backup/backup-a.bin
.\.venv\Scripts\python.exe -m esptool --chip esp8266 --port COM_N --baud 115200 read_flash 0x0 0x400000 local-backup/backup-b.bin
Get-FileHash local-backup/backup-a.bin,local-backup/backup-b.bin -Algorithm SHA256
```

Оба файла должны иметь4194304байта и одинаковый SHA256. Сохраните две копии в разных местах. Если чтение обрывается, хеши различаются или flash не4MiB — **ничего не записывайте**. Перед следующим чтением может понадобиться повторный вход в загрузчик. Пока восстановление через UART не доступно, прошивку не начинайте.

Бэкап может содержать Wi-Fi пароль и другие данные. Никому его не отправляйте, в GitHub не загружайте. Без своей копии вернуть OEM-прошивку/калибровку может не получиться. Чужой дамп не является заменой.

## 5. Создайте личную сборку

Узнайте и запишите текущий локальный IP своих часов в заводской панели/роутере. Не публикуйте его. Здесь `<ВАШ_IP>` — заполнитель, который нужно заменить; угловые скобки в команду не вводятся.

```powershell
.\.venv\Scripts\python.exe firmware/tools/build_assets.py
.\.venv\Scripts\python.exe firmware/tools/provision.py --host <ВАШ_IP>
.\.venv\Scripts\python.exe -m unittest discover -s firmware/tests
.\.venv\Scripts\python.exe -m platformio run -d firmware -e smalltv_ultra
.\.venv\Scripts\python.exe -m platformio run -d firmware -e smalltv_ultra -t buildfs
```

Эти шаги только создают файлы. Получатся firmware.bin и littlefs.bin в `firmware/.pio/build/smalltv_ultra/`. Ключ уникален и хранится локально в игнорируемых файлах. Не отдавайте свои бинарники, `private_config.h` или `device.json` другим людям.

## 6. Запись — только после успешных проверок

**Следующие команды реально меняют flash и могут привести к неработающим часам при ошибочной плате, адресах или контактах.** Для этого профиля приложение пишется в0x0, LittleFS в0x200000; хвост с0x3FA000 не стирается. Не используйте инструкции для ESP32 с отдельными bootloader/partition-table. Полный erase_flash для обычной установки не нужен.

```powershell
.\.venv\Scripts\python.exe -m esptool --chip esp8266 --port COM_N --baud 115200 write_flash --flash_mode dio --flash_freq 40m --flash_size 4MB 0x0 firmware/.pio/build/smalltv_ultra/firmware.bin 0x200000 firmware/.pio/build/smalltv_ultra/littlefs.bin
.\.venv\Scripts\python.exe -m esptool --chip esp8266 --port COM_N --baud 115200 verify_flash 0x0 firmware/.pio/build/smalltv_ultra/firmware.bin 0x200000 firmware/.pio/build/smalltv_ultra/littlefs.bin
```

Завершения записи недостаточно: требуется успешная проверка и обычный запуск. Если контакт пропал — не повторяйте запись бесконечно; обесточьте, исправьте соединение, проверьте загрузчик и сохранность бэкапа.

Обесточьте оба USB, снимите GPIO0→GND, затем включите обычное USB-питание часов. UART можно убрать только без питания и после проверки нормального запуска. Закрывайте корпус, не пережимая шлейф экрана.

## 7. Wi-Fi и служба

Если прежняя домашняя сеть сохранилась — найдите часы в роутере. Если появляется AP MadyarMini-…: подключитесь к ней однократно. Пароль AP — первые12символов вашего локального `key` из `firmware/private/device.json`; его нельзя показывать на видео. Шлюз AP определите на своём ПК через сведения подключения.

```powershell
.\.venv\Scripts\python.exe firmware/tools/configure_wifi.py --gateway <ШЛЮЗ_AP>
```

В своём терминале введите SSID/пароль домашней сети2,4ГГц; ввод скрыт. Затем вернитесь в домашнюю сеть, найдите новый IP часов и повторите `provision.py --host <НОВЫЙ_IP>`: ключ сохранится, прошивать повторно из-за смены IP не нужно.

```powershell
.\.venv\Scripts\pythonw.exe -m madyarmini.service_supervisor --live
```

Откройте локальную панель <http://127.0.0.1:8772/>. Для первых проб можно использовать симуляцию: `python -m madyarmini.integrated_service` без `--live`. Не открывайте порт панели или устройства в интернет. Настройте город, палитру и яркость в панели. Автозапуск в этой публичной версии сам не включается.

## 8. Codex

Следуйте [RUNTIME_SETUP.md](../RUNTIME_SETUP.md): генератор создаст marketplace для **вашей папки**, затем через Codex устанавливается локальный плагин и проверяются доверенные hooks. Настройки Codex не перезаписываются автоматически. На новой версии приложения названия/доступность команд могут отличаться; неподтверждённую интеграцию не называйте работающей.

Проверьте два локальных чата: два старта → WORKING2; один закончил ответ → WORKING1; запрос подтверждения → WARNING нужного чата; обычный ответ → короткий «Ответ готов»; только явное завершение задачи → DONE. Если событий нет, начинайте с журналов/источников панели, не с повторной прошивки.

## Восстановление

Только для того же устройства с вашим проверенным полным бэкапом4194304байта: вернитесь в UART-загрузчик и используйте esptool4.8.1 `write_flash 0x0 local-backup/backup-a.bin`, затем `verify_flash 0x0 local-backup/backup-a.bin`. Это осознанная запись всей flash с вашей калибровкой; не применяйте к чужим часам. При неуверенности сначала получите помощь, а не экспериментируйте с erase_flash.
